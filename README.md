# Ting for Claude Code

Write story packs for Ting, the game where you learn a language by living in a town. Claude plans and writes
them with you; Ting's service checks every version, plays your drafts on your phone, and publishes them after a
review.

In Claude Code:

```
/plugin marketplace add wontonwindmill/ting-plugin
/plugin install ting@ting
```

Then, in an empty folder, `/ting:new`. Start here: https://studio.tinglanguage.com/start. For now, Ting is invite-only.

The plugin itself, and what each command does: [ting/README.md](ting/README.md).
